# 플랜핏 (PlanFit) — 베타

AI 기반 대학생 학사·커리어 통합 설계 플랫폼 (공주대 행정학과 베타 데모)

## 폴더 구조

```
planfit/
├── index.html        ← 소개 랜딩페이지 (브랜드/사업 소개)
└── app/
    ├── index.html    ← 실제 작동하는 베타 앱
    └── data.js       ← 행정학과 졸업요건 + 교양과목 + 직무 데이터
```

## 앱 기능 (3단계)

1. **이수내역 입력** — 들은 과목을 탭으로 선택 (2024 행정학과 교육과정 + 공주대 교양 편성 기준)
2. **졸업 진단** — 총 130학점 대비 영역별 진행률, 미이수 필수과목 자동 표시
3. **시간표 추천** — 목표 직무 선택 시 직무 적합도 점수로 다음 학기 과목 추천 + 플랜 B 시뮬레이션

## 깃허브 Pages 올리는 법

1. 깃허브에서 새 저장소(repository) 생성 (예: `planfit`)
2. 이 폴더의 파일 전부를 업로드 (`index.html`, `app/` 폴더 통째로)
3. 저장소 → **Settings → Pages**
4. Source: `Deploy from a branch` → Branch: `main` → 폴더: `/ (root)` → Save
5. 1~2분 후 접속:
   - 랜딩: `https://[아이디].github.io/planfit/`
   - 앱: `https://[아이디].github.io/planfit/app/`

서버·데이터베이스 없이 브라우저에서 바로 작동합니다 (무료).

## 데이터 수정 방법

`app/data.js` 파일만 고치면 됩니다.
- `major` — 전공 과목 (이름, 학점, 구분, 필수여부, 학년/학기)
- `gen` — 교양 과목
- `req` — 졸업요건 (총학점, 전공필수 목록 등)
- `jobs` — 직무별 키워드 사전 (추천 알고리즘에 사용)

다른 학과로 확장하려면 이 파일의 데이터만 교체하면 됩니다.

## 데이터 출처

- 2024학년도 행정학과 교육과정 (전공 과목·졸업요건)
- 공주대 교양교과목 편성 현황 2026학년도 1학기 기준 (교양 과목)
